# 项目计划「全貌浏览」设计方案（分 Tab 多视图 + 关联）

> 目标：一个项目计划创建后，其全部内容**不堆在一页**，而是按维度分成多个独立 Tab（类似钉钉 AI WBS 的多 table），Tab 之间数据可关联联动。
> 本文档记录现状 + 下一步增强方案，供讨论。

---

## 一、现状（已实现）

进入某个计划详情（`#/plan/detail/<id>`）后，顶部是**页头概览条**（计划名/状态/年度/负责人/起止/团队成员 chips/参考文档），下方是 **7 个独立 Tab**，各自独立 table/视图，切换不刷新整页：

| Tab | 内容 | 数据源 | 说明 |
|---|---|---|---|
| 📋 **项目总览** | 固定 8 阶段大纲（阶段名/负责人/起止/状态/进度/交付物/备注） | `plan.overview[]` | 阶段级主线，**独立于 WBS**；空态可一键初始化，支持行内增删改查+保存 |
| 🌳 WBS 任务 | 任务树（父子层级/类型/状态/优先级/人天/进度/起止/依赖） | `plan.tasks[]` | 任务级明细 |
| 📊 甘特图 | 任务时间轴（泳道/时段条/进度填充） | `plan.tasks[]` | 从 WBS 派生 |
| 🎯 里程碑 | 关键节点时间线 | `plan.milestones[]` | |
| 👥 资源负荷 | 资源产能 vs 任务负荷，超载识别 | `plan.resources[]` + tasks owner 聚合 | |
| 📊 高管视图 | 整体进度/里程碑达成/风险清单（本地规则计算） | 汇总 `/api/plan/summary` | 只读指挥舱 |
| 🤖 AI 规则 | 本地规则生成（WBS模板/资源缺口/周报），预留 AI 入口 | 规则引擎 | 未接外部模型 |

- 默认进入落在「📋 项目总览」。
- 每个计划数据完全独立在 `data/plan/state.json` 的一条 `plan` 里，互不干扰。

---

## 二、参考钉钉 AI WBS 的做法（要吸收的点）

1. **多 table 分视图**：总览、任务、排期、资源、成员各成一个可切换的表，避免信息过载。✅ 现状已具备雏形。
2. **table 间关联**：如「WBS 任务」的负责人 = 「成员」表里的人；「甘特」时间轴 = 「WBS」的起止；「高管视图」的风险 = 「WBS」逾期任务。**联动而非重复录入。**
3. **一处修改、多处生效**：改 WBS 的进度，甘特/高管视图/总览同步反映。

## 三、下一步增强方案（待确认后实现）

### 增强 1：总览 ↔ WBS 的关联（弱关联，不强绑）
- 现状：总览 8 阶段与 WBS 任务是两套独立数据（符合"总览看阶段、WBS 看任务"的定位）。
- 增强：给 WBS 任务一个可选的「所属阶段」下拉（值来自总览的 8 阶段名）。这样：
  - 总览每个阶段可自动汇总「该阶段下 WBS 任务的进度/人天」，显示一个派生进度；
  - 高管视图的「阶段推进」直接用总览阶段 + 关联任务，口径统一。
- 好处：总览成为"纲"，WBS 成为"目"，纲举目张，且不强制——没关联的任务照常在 WBS 里。

### 增强 2：成员 ↔ 任务/阶段负责人的关联
- 「团队成员」表登记的人，供 WBS 任务、总览阶段、里程碑的「负责人」字段做下拉候选（而非手输），减少错别字、方便统计每人负载。

### 增强 3：Tab 顶部统一「概览指标条」
- 详情页头部加一排小指标（总任务/已完成/整体进度/风险数/里程碑达成），任何 Tab 都能一眼看到项目健康度（类似列表页的 metric strip，但针对单个计划）。

### 增强 4：Tab 深链接 + 记忆
- 现状 hash 已支持 `#/plan/detail/<id>/<tab>`，但通过 hash 直接进入时未强制重渲染（点击卡片进入是正常的）。可补一个 `enter()` 里的 `render()`，让直接粘贴链接也能落到指定 tab。

### 增强 5（远期）：详细计划
- 用户已明确：详细 WBS 不按阶段、直接照需求清单拆。待用户确认粒度后，在 WBS Tab 增加"按需求清单批量生成任务"的入口（复用之前写过的需求解析逻辑，只是产出到 WBS 而非总览）。

---

## 四、建议的落地顺序

1. **增强 3（头部指标条）** — 成本低、体验提升明显。
2. **增强 2（成员做负责人下拉）** — 关联的第一步，减少重复录入。
3. **增强 1（总览↔WBS 阶段关联）** — 让总览真正成为"纲"。
4. **增强 4（深链接重渲染）** — 小修。
5. **增强 5（详细计划）** — 待用户定粒度。
